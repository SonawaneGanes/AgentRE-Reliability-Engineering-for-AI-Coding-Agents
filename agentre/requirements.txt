AgentRE – Reliability Engineering for AI Coding Agents

AgentRE is a reliability engineering framework for AI coding agents. 
It combines code generation, execution, failure detection, debugging, 
repair, and re-testing into a reliability loop.

Tech Stack:
- Python
- Ollama
- Gemma 3 4B
- Pytest
- Hypothesis
- Git
- Docker

Core Workflow:

AI Code Generation
        ↓
Code Execution
        ↓
Failure Detection
        ↓
Debugger Agent
        ↓
Code Repair
        ↓
Re-testing
        ↓
Verified Result

Project Highlights:
- CoderAgent
